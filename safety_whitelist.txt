# 永不删除白名单（grep -E 正则，一行一条，匹配 = 拒绝卸载）
# apply_debloat_v2.sh 会先读本文件，命中即拒绝执行，不靠人记。
#
# 血的教训（2026-10-19）：
#   ① Antigravity 的 batch 2 把 mstar.factorymenu.ui 当"臃肿"删了，
#      而它是这台电视【唯一的 ADB 开关入口】→ 删完就再也打不开 ADB。
#   ② 我们把 com.sharp.fxc.shortcut 当"快捷方式"删了，结果【设置直接崩溃】
#      （MainBasePage.getHomePageInfo → Cursor 为 null 的 NPE）。
#      它是设置首页的 ContentProvider 数据源，属于隐性硬依赖。
#   ③ 系统应用的 APK 可能是【无 dex】的（代码在 /system/app/X/oat/arm64/X.odex），
#      这种包用 U 盘装到 /data 必然 classNotFound，装回去也打不开（本次踩过）。
#      正确恢复法是 `pm uninstall <pkg>` 让它退回 /system 原厂版，不是 pm install。
#   ④ 【2026-10-19】"从没启动过" ≠ "没用"。com.trim.tv 名字像腾讯系预装器，
#      PSS=0 也从没跑过，打开却是【飞牛TV】，而且已经配好了 DellNAS 192.168.1.80:8005。
#      差点把你正在用的 NAS 播放器当臃肿删了。
#      → 判定任何包之前，必须 `am start` 打开看一眼，或查它有没有配置数据。
# 本文件的全部意义：让机器来拦上面这些事，不靠人记。
# ---------------------------------------------------------------------------
